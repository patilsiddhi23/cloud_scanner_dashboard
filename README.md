Cloud computing platforms provide scalable infrastructure and services for storing applications and data. However, securing these resources can be difficult with fragmented tools or manual examinations. Crucial cloud security breaches can result from misconfigured cloud services, leading to risks like data leakage, system breach, etc. To address these challenges, this project presents an Automated Cloud Security Misconfiguration Detection System for AWS environments. The system is implemented in Python using the Boto3 SDK to interact with AWS cloud services and retrieve configuration details from resources such as S3 buckets, IAM policies, EC2 instances, and security groups. A misconfiguration detection module analyses these configurations against predefined security rules to identify vulnerabilities. The system classifies findings based on severity levels and generates detailed security reports for affected resources. To further improve usability, integration of the Google Gemini large language model to generate plain-language explanations and remediation guidance for detected vulnerabilities is done, enabling faster analysis and response to cloud security risks.
